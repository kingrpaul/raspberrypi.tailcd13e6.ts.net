1. Install :code:`Tweaks` from the software store or confirm that it is installed.

  .. image:: /posts/2024-03-10_eo-on-us-kbd-with-ubuntu-2204/fig1.jpg
    :width: 90%
    :alt: screen image

2. Launch :code:`Tweaks`. From the :code:`Keyboard & Mouse` section, select :code:`Additional Layout Options`.

  .. image:: /posts/2024-03-10_eo-on-us-kbd-with-ubuntu-2204/fig2.jpg
    :width: 90%
    :alt: screen image

3. From the :code:`Esperanto letters with superscripts` selector, select :code:`At the corresponding key in a QWERTY layout`.

  .. image:: /posts/2024-03-10_eo-on-us-kbd-with-ubuntu-2204/fig3.jpg
    :width: 90%
    :alt: screen image

4. From the :code:`Key to choose the 3rd level` selector, select only :code:`Left Alt` and :code:`Right Alt never chooses 3rd level`. 

  .. image:: /posts/2024-03-10_eo-on-us-kbd-with-ubuntu-2204/fig4.jpg
    :width: 90%
    :alt: screen image

To type an Esperanto letter that contains a diacritic (*ĉ*, *ĝ*, *ĥ*, *ĵ*, *ŝ*, or *ŭ*), press the :code:`Lt-Alt` key along with the corresponding letter lacking a diacritic. The :code:`Rt-Alt` key remains available for alternate functions.
